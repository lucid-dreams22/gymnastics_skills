# High School Gymnastics Skill Helper

A small Streamlit app for browsing selected high-school varsity gymnastics skills.

## Files

- `app.py` — website/interface
- `skills_data.py` — gymnastics skill database
- `requirements.txt` — Python dependency list

## Run locally

Open a terminal inside this folder and run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Streamlit will print a local URL, normally `http://localhost:8501`.

## Put it online

1. Create a GitHub repository.
2. Upload `app.py`, `skills_data.py`, and `requirements.txt` to the repository root.
3. Sign into Streamlit Community Cloud with GitHub.
4. Choose **Create app**.
5. Select the repository.
6. Set the entrypoint file to `app.py`.
7. Deploy.

The AI button is currently a placeholder. The rest of the skill browser works without an API key.
